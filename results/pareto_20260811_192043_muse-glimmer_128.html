Metric Definitions

ISL (Input Sequence Length)
Number of tokens in the input prompt. Varies across requests in multi-turn conversations.
OSL (Output Sequence Length)
Number of tokens generated by the model. Target was 128 tokens (+/- 32).
TTFT (Time to First Token)
Time from request start to first token received. Includes prefill phase and scheduling overhead.
ITL (Inter-Token Latency)
Average time between consecutive output tokens during decode phase. Lower is better.
E2E Latency (End-to-End)
Total request time from start to last token received. = TTFT + (OSL - 1) * ITL.
Decode Phase Duration
Time spent generating tokens after first token. = E2E Latency - TTFT.
Decode Speed (tok/s)
Actual token generation rate during decode phase. = OSL / Decode Phase Duration. This is the true decode performance.
Req/s (Request Throughput)
Total requests completed per second. Affected by concurrency level.
tok/s/W (Tokens per Watt)
Energy efficiency: output tokens generated per Joule of GPU energy consumed.
Example (Muse-Glimmer-30B, text, c1):
ISL=301 tokens, OSL=127 tokens, TTFT=992 ms, ITL=125 ms
E2E Latency = 992 + (127-1) * 125 = 16,742 ms
Decode Phase = 16,742 - 992 = 15,750 ms
Decode Speed = 127 / 15.75 = 8.1 tok/s
Note: Decode Speed vs Throughput tokens/s
Decode Speed (tok/s) = OSL / Decode Phase Duration. This measures how fast the model generates tokens during active generation. It reflects the model's raw decode performance.

Throughput tokens/s (in GPU Efficiency chart) = Total Output Tokens / Benchmark Duration. This includes idle time between requests and is affected by concurrency. At c1, it equals Decode Speed. At higher concurrency, it can exceed Decode Speed because multiple requests generate tokens in parallel.

When to use which: Use Decode Speed to compare model inference performance. Use Throughput to measure system-level capacity.
