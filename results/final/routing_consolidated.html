3. Cross-Model Architecture Insights

Dense vs MoE

Muse (Dense): 30B params always active. Consistent compute, no routing overhead.

MoE Models: 3B active params per token. Conditional compute, routing overhead, load balancing required.

Hybrid vs Pure MoE

Nemotron (Hybrid): 29 Mamba layers (constant-time) + 23 MoE layers. Lower entropy due to Mamba layers.

Qwen (Pure MoE): All layers are MoE. Expected higher entropy (~0.85-0.90).

Precision Impact

NVFP4 (4-bit): May affect routing decisions due to lower precision activations.

FP8 (8-bit): More stable routing, minimal precision impact.

Expert Selection

Nemotron: Top-6 from 256 experts (2.3% utilization).

Qwen: Top-8 from 256 experts (3.1% utilization). Slightly higher per-token compute.

5. How to Run Missing Probes

Prerequisites:
  • vLLM Python module must be available in the environment
  • Model server must be running with enable_return_routed_experts=True
  • Input datasets must be in JSONL format

Quick Start Commands

# For Qwen FP8:
./launch_vllm_qwen_fp8.sh
PROBE_MODEL=nvidia/Qwen3.6-35B-A3B-FP8 python3 router_probe.py --text multi_turn_iso_text_chat.jsonl --random multi_turn_iso_random_chat.jsonl --reasoning multi_turn_iso_reasoning_chat.jsonl --limit 20 --out results/final/qwen_fp8/routing/probe

# For Qwen NVFP4:
./launch_vllm_qwen_nvfp4.sh

Architecture Differences

  • Nemotron: 29 Mamba + 23 MoE layers (hybrid)
  • Qwen: 40 MoE layers (pure MoE)
  • Entropy gap: Qwen multi-turn entropy is 2.4x higher
  • Position effect: Qwen shows stronger position dependence
Key finding: The most striking difference is in multi-turn entropy: Qwen NVFP4 (0.83-0.85) is 2.4x higher than Nemotron (0.35). This is primarily because Nemotron's Mamba layers have entropy ≈ 0, which drags down the average. Qwen's pure MoE architecture means all 40 layers contribute to routing diversity. In single-turn, the MoE-only entropy is comparable (Nemotron ~0.75-0.77, Qwen ~0.76-0.79), confirming that the architecture difference (hybrid vs pure) is the main driver of the entropy gap.

7. Open Research Questions

FP8 vs NVFP4 Routing

Answered: FP8 and NVFP4 show identical routing patterns (differences < 1%). 4-bit quantization does not materially affect routing decisions. NVFP4 provides 4x memory savings without routing degradation.

Pure MoE vs Hybrid

Answered: Qwen's pure MoE shows 2.4x higher multi-turn entropy than Nemotron's hybrid. The single-turn MoE-only entropy is comparable (~0.76-0.79).

Content Dependence

Both models are content-agnostic. Qwen shows slightly more variation (random 0.785 vs text 0.761) than Nemotron (0.755 vs 0.771).

Position Effects

Confirmed universal: both models show early→late entropy increase. Qwen's effect is stronger (6-12% vs 3-5%), suggesting pure MoE has more routing flexibility.
