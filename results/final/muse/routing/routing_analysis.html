Muse-Glimmer-30B — Routing Analysis

Architecture analysis for meta-models/Muse-Glimmer-30B on Dell Enterprise AI

No MoE Routing: Muse-Glimmer-30B is a Dense Transformer (not a Mixture-of-Experts model). It does not have a router or expert selection mechanism. Every token passes through all parameters in every layer. This report documents the architectural differences and explains why routing probes are not applicable.

2. Dense vs MoE Architecture

MUSE (Dense)

  • ✅ 30B parameters active per token
  • ✅ Consistent compute across all inputs
  • ✅ No routing overhead
  • ✅ Predictable memory usage
  • ❌ Higher compute per token
  • ❌ No conditional computation
VS

NEMOTRON/QWEN (MoE)

  • ✅ 3B active params per token (conditional)
  • ✅ Lower compute per token
  • ✅ Expert specialization
  • ✅ Higher total capacity
  • ❌ Routing overhead
  • ❌ Load balancing challenges

3. Why Routing Probes Don't Apply

Routing Probe Purpose: The routing probe (router_probe.py) captures per-token expert selection from vLLM's enable_return_routed_experts flag. This flag only works with MoE models that have a router module (like Qwen3.6-35B-A3B or Nemotron's Gated DeltaNet MoE layers).

4. Performance Implications

Throughput Characteristics

Muse processes all 30B parameters for every token, which means:

  • Higher FLOPs per token
  • More consistent latency (no routing variance)
  • Better for small batch sizes
  • May underperform MoE at high concurrency

Memory Characteristics

Dense models have different memory profiles:

  • All 30B params must be in memory
  • No expert offloading possible
  • KV cache is the main variable
  • FP8/INT4 quantization helps significantly

5. Recommendation

For routing analysis, focus on:
  • Nemotron 3.5 Lightning: Hybrid Mamba-MoE with 256 experts, top-6 routing (see Nemotron routing report)
  • Qwen3.6-35B-A3B: Pure MoE with 256 experts, top-8 routing (probe not yet run)

Muse's performance should be analyzed through throughput/latency benchmarks (Pareto reports) rather than routing probes.
