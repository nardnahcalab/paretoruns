Key Takeaways

Mamba Constant-Time Confirmed

512x more input = only 3.5x more latency. A pure transformer would show ~4,000x increase at these lengths. The Mamba SSM layers eliminate the quadratic attention bottleneck.

250K Context is Feasible

At 128K tokens, total latency is 2.8s with 128 output tokens. For 250K, estimated latency is ~5-6s — within interactive response budgets for agentic workflows.

Speculative Decoding Helps

DSpark provides 1.16-1.46x speedup across all concurrency levels. The overhead of the draft model is small relative to the throughput gain.

Hybrid Architecture Wins

56% of layers are constant-time Mamba. 44% are capacity-providing MoE. This split is optimal for long-context agentic workloads at scale.
