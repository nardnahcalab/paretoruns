9. Infrastructure Implications

9.1 Key Findings

ExperimentFindingImplication
A4: Prefix CachingMinimal benefit for short promptsFocus on longer system prompts for caching
B3: Mixed-ConcurrencySublinear scaling with variable outputsNeed capacity margin for real-world workloads
C2: Tool-Call RoutingNo difference from plain textTool calls don't stress different experts
C3: System Prompt Reuse1.85x speedup for large promptsUse shared system prompts in agentic workflows
C4: Interleaved R/WRead phase dominates (2.14x)Optimize tool result processing

9.2 Recommendations

1. Use large system prompts for caching: System prompt caching is effective (1.85x) for prompts > 800 tokens. Design agentic workflows with shared, detailed system prompts.
2. Account for variable output lengths: Mixed-concurrency shows sublinear scaling. Add 30-50% capacity margin for real-world workloads with variable output lengths.
3. Optimize tool result processing: Read phase dominates agent loops. Consider streaming tool results or parallel processing.
